# AI Learning Journey

A hands-on repository focused on understanding and building core AI, machine learning, and deep learning concepts through practical notebooks and experiments.

This repo is a learning archive where I explore classical ML, CNNs, transformer internals, attention mechanisms, and model-building workflows using real datasets and from-scratch implementations.

## What this repo covers

- Linear regression and regression workflows
- CNNs on CIFAR-10
- Data cleaning, preprocessing, and feature engineering
- Classification on Titanic
- Transformer and attention implementations from scratch
- RoPE (Rotary Positional Embedding) and positional encoding concepts
- Practical notebook-based experimentation in PyTorch and scikit-learn

## Repository highlights

### Machine learning notebooks
- `LR_housing_price.ipynb` — linear regression practice on housing price data
- `california_housing_project.ipynb` — California housing analysis and modeling workflow
- `titanic.ipynb` — dataset exploration, preprocessing, and classification practice

### Deep learning and CNNs
- `CNN_p1_CIFAR10.ipynb` — CNN experimentation on CIFAR-10 with normalization, augmentation, and model comparison

### Transformers and attention
- `transformers_attention.ipynb` — self-attention and multi-head attention implemented from scratch in PyTorch
- `transformer_decoder.ipynb` — decoder architecture exploration
- `RoPE_in_transformer.ipynb` — hands-on understanding of rotary positional embeddings

## Notable learning outcomes

- Built CNN models and trained them on CIFAR-10
- Explored data preprocessing, validation, normalization, and augmentation patterns
- Implemented transformer attention logic manually instead of relying only on libraries
- Learned core concepts behind positional encodings and attention-based architectures

## Example results from the notebooks

- CIFAR-10 CNN notebook reported around `0.83` test accuracy with a custom PyTorch CNN pipeline
- Housing and Titanic notebooks demonstrate end-to-end data science workflows, including EDA, cleaning, and modeling experiments

## How to use this repository

1. Clone the repo
2. Open the notebooks in Jupyter, VS Code, or JupyterLab
3. Run them in order for the learning progression
4. Use the notebooks as study material or as a base for expanding into more advanced projects

```bash
git clone https://github.com/raj318/ai.git
cd ai
jupyter notebook
```
